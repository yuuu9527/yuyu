# StageQuick Companion

仅用于原版 Dynamic Stage 1.2（`me.tomt000.stageduo`）。保留原包、原手势、原面板与原设置；本包无设置文件写入，不修改第三方文件，也不打包原作者的二进制或素材。卸载旧的独立版 `com.yu.stagequick` 后，保留或装回原版，然后安装本包；仅卸载本配套包即可撤销点按变化，无须清理原版偏好文件。

点按普通应用卡片时调用原包已有的长按全屏路径，沿用原生关闭与启动流程。原包仍安装，这个版本**没有全局禁用原版独立的拖拽分屏手势**。目标方法与签名不匹配时不修改原版行为。仅 SpringBoard 注入。

已对输入 deb 静态核对原版应用选择与长按方法；不代表设备运行结果。建议先在原版面板长按任意应用确认全屏，再安装配套包，用同一 App 测试单点。
